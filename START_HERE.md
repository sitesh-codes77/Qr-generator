## ⚡ Quick Start (2 minutes)

### 1. Start Backend
```bash
cd backend
npm install
npm run dev
```
Server: `http://localhost:5000`

### 2. Start Frontend (New Terminal)
```bash
cd frontend
npm install
npm start
```
App: `http://localhost:3000`

### 3. Test It
- Enter any UPI ID (e.g., `testuser@paytm`)
- Create password
- Click "Make Payment"
- Try entering amount and scanning QR

## 🎯 Features Overview

### User Flow
1. **First Visit**: Enter UPI ID & password → Account created
2. **Dashboard**: Welcome screen with payment option
3. **Amount Entry**: Select or enter payment amount (₹1-₹100,000)
4. **QR Scanning**: Real-time camera scan of UPI QR code
5. **Payment**: Automatic redirect to UPI app with pre-filled amount
6. **Auto-Login**: Subsequent visits automatically logged in

### Security Features
- 🔒 Password hashing (bcryptjs)
- 🔐 JWT authentication (7-day expiration)
- ⚡ Rate limiting (100 req/15 min)
- ✓ Input validation & sanitization
- 🛡️ Security headers (Helmet)
- 🔄 CORS protection
- 🚫 XSS protection

### Tech Stack
- React 18 + Tailwind CSS (Frontend)
- Node.js + Express.js (Backend)
- MongoDB (Database)
- html5-qrcode (QR Scanning)
- JWT + bcryptjs (Security)
